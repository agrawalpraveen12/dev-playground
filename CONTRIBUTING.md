# Contributing Guide

Thank you for your interest in contributing to this project!

## Getting Started

1. Fork this repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/dev-playground.git`
3. Add the upstream remote: `git remote add upstream https://github.com/agrawalpraveen12/dev-playground.git`

## How to Contribute

1. Create a new branch: `git checkout -b feature/your-feature`
2. Make your changes and commit: `git commit -m 'feat: add your feature'`
3. Push to your branch: `git push origin feature/your-feature`
4. Open a Pull Request against `main`

## Commit Message Convention

We follow [Conventional Commits](https://www.conventionalcommits.org/):

- `feat:` — a new feature
- `fix:` — a bug fix
- `docs:` — documentation changes
- `refactor:` — code refactoring
- `test:` — adding or updating tests
- `chore:` — maintenance tasks

## Code Style

- Write clear, readable code with descriptive variable names
- Add inline comments for non-obvious logic
- Keep functions small and focused
- Follow existing conventions in the codebase

## Reporting Issues

Please open a GitHub Issue with:
- A clear, descriptive title
- Steps to reproduce the problem
- Expected vs actual behavior
- Your environment (OS, language version)

## Code of Conduct

Be respectful and inclusive. We follow the [Contributor Covenant](https://www.contributor-covenant.org/).
